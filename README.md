# CleanDesk

CleanDesk 是一个本地自动整理指定文件夹中文件的桌面工具。

当前版本：0.6.1-beta

开发者：Zmx

## CleanDesk 0.6.1-beta

本版本新增并完善 Windows 后台通知：

- 新增后台通知与设置开关，默认开启；
- 设置页可直接发送测试通知；
- 开机静默启动并自动整理时显示启动结果；
- 监控文件夹不可用时显示简洁提醒；
- 自动整理因重名跳过时，在短时间内合并提醒；
- 手动整理完成后汇总整理、跳过和忽略数量；

- 优化通知中文文案，使用“已整理”等自然表达。

通知只是额外反馈。关闭通知后，最近活动、详细日志和撤销仍会正常工作。普通文件整理成功和按规则忽略的文件不会逐条发送通知，避免频繁打扰。

## CleanDesk 0.6.0-beta

CleanDesk 是一个本地自动化文件管家。本版本在多监控文件夹、全局整理规则、忽略规则和智能整理建议的基础上，新增并完善：

- 设置中心；
- 启动 CleanDesk 后自动开始整理；
- 开始整理时是否扫描已有文件；
- 手动整理和自动监听的重名处理策略；
- 最近活动数量设置与清空功能；
- 系统托盘和关闭到托盘；
- Windows 登录后自动启动；
- 开机静默进入托盘，不显示 CMD；
- 单实例保护，第二次启动会唤醒已有窗口；
- 所有整理均在本机完成，不上传文件。

`Windows 登录后自动启动 CleanDesk` 只决定 Windows 登录后是否启动软件；`启动 CleanDesk 时自动开始整理` 决定软件启动后是否开始监听，两者相互独立。

开机启动使用内部 `--startup` 参数静默进入托盘。用户手动打开 CleanDesk 时仍会正常显示主窗口。所有监控文件夹共享同一套规则和设置。

## 使用步骤

1. 打开 `CleanDesk.exe`
2. 添加一个或多个测试文件夹
3. 选择当前要整理的文件夹
4. 点击“整理当前文件夹”
5. 确认分类结果正确
6. 点击“开始自动整理”启用自动监听
7. 需要暂停时点击“停止自动整理”
8. 如需恢复最近一次整理结果，可点击“撤销上一次整理”

## 多监控文件夹

- CleanDesk 可以同时管理多个监控文件夹。
- “开始自动整理”会扫描并监听所有监控文件夹。
- “整理当前文件夹”只整理当前选中的文件夹。
- “智能整理建议”只分析当前选中的文件夹。
- 规则是全局共享的，会应用到所有监控文件夹。
- 相对目标文件夹会在每个来源文件夹内创建。
- 绝对目标路径会直接使用，不会拼接到来源文件夹下。
- 自动整理运行中不能添加或移除监控文件夹，需要先停止。
- 最近活动会显示文件来自哪个监控文件夹。

## 默认规则说明

- 图片 -> `图片`
- PDF -> `PDF文档`
- 视频 -> `视频`
- 音频 -> `音频`
- 文件名包含“发票” -> `发票`
- 文件名包含“课程” -> `课程资料`

## 安全提示

- CleanDesk 会移动文件，而不是复制文件。
- 第一次使用请不要直接监控重要的 `Downloads` 或 `Desktop`。
- 首次使用建议选择测试文件夹，先确认整理结果符合预期。
- Beta 版本建议保留重要文件备份。
- “撤销上一次整理”仅在当前程序运行期间有效，关闭程序后不会保留撤销历史。

## 最近活动

最近活动会显示文件整理结果，例如已整理、未整理、撤销完成等。

对于已整理的文件，最近活动会显示它命中了哪条规则，方便确认文件为什么被移动到对应文件夹。

对于已整理的文件，可以点击“打开所在位置”，在 Windows 文件资源管理器中查看目标文件夹，并尽量选中对应文件。

## 规则优先级

规则从上到下依次匹配。

- 第一个匹配成功的规则会决定文件移动位置。
- 可以拖动规则项调整规则优先级。
- 最近活动会显示每个文件命中了哪条规则。
- 如果某个文件同时符合多条规则，列表中更靠上的规则优先生效。

例如：

- `发票.pdf` 会优先进入 `发票`。
- `课程笔记.pdf` 会优先进入 `课程资料`。
- 普通 PDF 文件才会进入 `PDF文档`。

## 智能整理建议

CleanDesk 可以分析当前选中文件夹顶层的文件类型数量，推荐尚未被现有规则覆盖的整理规则。

- 只分析文件名、扩展名和数量。
- 不读取文件内容。
- 不联网、不上传文件。
- 不会自动移动文件，必须由用户确认。
- 可以选择“仅添加规则”，也可以选择“添加规则并整理”。

## 撤销说明

CleanDesk 支持撤销上一次整理批次：

- “整理当前文件夹”移动的文件会作为一个批次撤销。
- “开始自动整理”时启动前扫描移动的文件会作为一个批次撤销。
- 自动监听整理的新文件会作为单文件批次撤销。
- 撤销只影响成功移动过的文件。
- 如果原位置已有同名文件，CleanDesk 会避免覆盖。

撤销历史只保存在内存中，程序关闭后不再可用。
