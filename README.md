# CleanDesk

CleanDesk 是一个本地自动整理指定文件夹中文件的桌面工具。

当前版本：0.4.0-beta

开发者：Zmx

## 当前功能

- 手动立即扫描
- 点击“开始”后先扫描已有文件，再监听新文件
- 自动监听新文件
- 按扩展名分类
- 按关键词分类
- 重名文件自动避免覆盖
- 最近活动记录
- 最近活动支持“打开所在位置”
- 最近活动会显示命中规则
- 支持通过规则左侧 ↑ / ↓ 调整优先级
- 支持撤销上一次整理
- 智能整理建议：根据当前文件夹中的高频文件类型推荐新规则
- 操作日志

## 使用步骤

1. 打开 `CleanDesk.exe`
2. 选择一个测试文件夹
3. 点击“立即扫描”
4. 确认分类结果正确
5. 点击“开始”启用自动监听
6. 需要暂停时点击“停止”
7. 如需恢复最近一次整理结果，可点击“撤销上一次整理”

## 默认规则说明

- 图片 -> `图片`
- PDF -> `PDF文档`
- 视频 -> `视频`
- 音频 -> `音频`
- 文件名包含“发票” -> `发票`
- 文件名包含“课程” -> `课程资料`

## 安全提示

- CleanDesk 会移动文件，而不是复制文件。
- 第一次使用请不要直接监控重要的 `Downloads` 或 `Desktop`。
- 首次使用建议选择测试文件夹，先确认整理结果符合预期。
- Beta 版本建议保留重要文件备份。
- “撤销上一次整理”仅在当前程序运行期间有效，关闭程序后不会保留撤销历史。

## 最近活动

最近活动会显示文件整理结果，例如已整理、未整理、撤销完成等。

对于已整理的文件，最近活动会显示它命中了哪条规则，方便确认文件为什么被移动到对应文件夹。

对于已整理的文件，可以点击“打开所在位置”，在 Windows 文件资源管理器中查看目标文件夹，并尽量选中对应文件。

## 规则优先级

规则从上到下依次匹配。

- 第一个匹配成功的规则会决定文件移动位置。
- 可以通过规则左侧的 ↑ / ↓ 调整规则优先级。
- 最近活动会显示每个文件命中了哪条规则。
- 如果某个文件同时符合多条规则，列表中更靠上的规则优先生效。

例如：

- `发票.pdf` 会优先进入 `发票`。
- `课程笔记.pdf` 会优先进入 `课程资料`。
- 普通 PDF 文件才会进入 `PDF文档`。

## 智能整理建议

CleanDesk 可以分析当前监控文件夹顶层的文件类型数量，推荐尚未被现有规则覆盖的整理规则。

- 只分析文件名、扩展名和数量。
- 不读取文件内容。
- 不联网、不上传文件。
- 不会自动移动文件，必须由用户确认。
- 可以选择“仅添加规则”，也可以选择“添加规则并整理当前文件夹”。

## 撤销说明

CleanDesk 支持撤销上一次整理批次：

- “立即扫描”移动的文件会作为一个批次撤销。
- “开始”时启动前扫描移动的文件会作为一个批次撤销。
- 自动监听整理的新文件会作为单文件批次撤销。
- 撤销只影响成功移动过的文件。
- 如果原位置已有同名文件，CleanDesk 会自动避免覆盖。

撤销历史只保存在内存中，程序关闭后不再可用。

## 打包与运行

开发者运行：

```powershell
pip install -r requirements.txt
python main.py
```

开发者打包 Windows Beta：

```powershell
build_windows.bat
```

普通用户运行：

```text
dist\CleanDesk\CleanDesk.exe
```
