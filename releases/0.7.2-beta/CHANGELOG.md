# CleanDesk 0.7.2-beta

## 新增

- 新增 Windows 安装程序，面向普通用户提供简体中文安装向导；
- 支持开始菜单快捷方式；
- 支持可选桌面快捷方式；
- 支持 Windows 标准卸载；
- 安装完成后可直接运行 CleanDesk。

## 优化

- 默认采用当前用户安装，不需要管理员权限；
- 默认安装到当前用户的 LocalAppData；
- 保留免安装 Windows 便携版；
- 优化 README 中面向普通用户的下载说明。

## 数据说明

- 安装包不包含用户配置、日志、监控路径或测试数据；
- 覆盖安装不会用默认配置覆盖已有配置；
- 卸载默认保留程序运行后生成的配置和日志，不会删除用户整理的文件。
