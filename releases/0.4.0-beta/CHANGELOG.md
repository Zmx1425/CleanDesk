# CleanDesk 0.4.0-beta

## 新增

- 智能整理建议；
- 本地统计当前监控文件夹中高频、未被规则覆盖的文件类型；
- 支持“仅添加规则”；
- 支持“添加规则并整理当前文件夹”；
- 智能建议支持自定义目标文件夹；
- 智能建议兼容相对路径与绝对路径。

## 已有核心能力

- 手动立即扫描；
- 自动监听新文件；
- 点击“开始”时先扫描已有文件，再监听新文件；
- Stop 停止监听；
- 按扩展名和文件名关键词整理文件；
- 规则优先级；
- 规则新建、编辑、删除、排序；
- 最近活动；
- 查看详细日志；
- 打开所在位置；
- 撤销上一次整理；
- 撤销期间避免被监听再次整理；
- 重名文件冲突处理；
- 相对路径与绝对路径目标目录；
- Windows PyInstaller 打包运行。

## 已修复

- 最近活动不再显示原始英文开发日志；
- 绝对目标路径不会被错误拼接到监控文件夹内；
- 撤销时移回的文件不会立刻被监听重新整理；
- 没有可撤销内容时，撤销按钮显示为明确的禁用状态；
- 智能整理建议弹窗文案与确认按钮顺序已优化。

## 已知限制

- 当前主要面向 Windows 桌面环境；
- 当前只支持一个监控文件夹；
- 撤销记录仅在本次程序运行期间有效；
- 智能建议只分析文件名、扩展名与数量，不读取文件内容；
- 智能建议只分析监控文件夹顶层文件，不递归分析子文件夹。
