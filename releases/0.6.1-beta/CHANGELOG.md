# CleanDesk 0.6.1-beta

## 新增

- Windows 后台通知；
- 后台通知开关；
- 测试通知；
- 自动启动结果通知；
- 监控文件夹不可用提醒；
- 自动重名跳过聚合通知；
- 手动整理结果汇总通知。

## 优化

- 手动整理通知显示来源文件夹名称；
- 自动隐藏数量为 0 的统计项；
- 使用“已整理”等自然中文文案；
- 通知采用节流和去重，避免逐文件打扰；
- 主窗口在前台时可抑制普通完成通知；
- 关闭通知不影响最近活动、详细日志和撤销。

## 已知限制

- 当前仅支持 Windows；
- Windows 系统通知总开关关闭时，CleanDesk 无法显示通知；
- 源码运行时，Windows 通知发送者可能显示为 Python；
- 正式打包版应显示 CleanDesk；
- 暂无通知历史页；
- 暂无通知声音单独设置；
- 暂无深色模式。
