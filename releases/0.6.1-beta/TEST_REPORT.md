# CleanDesk 0.6.1-beta 测试记录

## 已自动验证

- `notifications_enabled` 默认开启，非法值回退为默认值；
- 关闭通知后统一通知入口返回禁用状态；
- 测试通知、自动启动结果、文件夹不可用和手动整理汇总均通过统一通知入口；
- 自动启动成功与失败具有单次通知保护；
- 自动重名跳过支持单文件名称提示和多文件短时聚合；
- 手动整理汇总包含当前文件夹名称，不显示数量为 0 的项目；
- 无处理结果时显示“暂无需要整理的文件”；
- 通知管理器退出时停止聚合定时器并清空待发送项目；
- 通知开关不改变最近活动、详细日志或撤销数据；
- 使用临时配置和两个临时目录验证了文件夹管理、普通规则、忽略规则、手动整理、Start/Stop、自动监听和撤销；
- `python -m compileall .` 通过。

## 已人工确认

- 用户已确认真实 Windows 环境能够显示 CleanDesk 后台通知；
- 用户已确认手动整理汇总通知能够出现；
- 用户反馈确认通知功能正常，随后针对中文文案提出并完成优化。

## 发布包复核

- PyInstaller 使用 windowed bootloader 构建成功，发布包中包含完整 `CleanDesk` 目录；
- 从 Windows ZIP 解压到全新临时目录后，`CleanDesk.exe` 可独立启动；
- 普通启动显示主窗口，未出现 CMD 窗口；
- About 和设置中心均显示 `0.6.1-beta`；
- 设置中心存在后台通知开关和“发送测试通知”按钮；
- `--startup` 启动时主窗口保持隐藏；
- 后台实例存在时再次普通启动会唤醒原窗口，第二个进程快速退出；
- 通过真实 `Alt+F4` 关闭窗口后进程正常退出；
- 最新文件夹名称与零项隐藏文案已自动验证，建议在发布包中再做一次目视确认；
- 托盘图标视觉、测试通知横幅和 Windows 通知中心历史展示受系统通知设置影响，需在目标机器上人工复核。

本记录仅描述实际执行或已由用户确认的场景，不代表所有 Windows 环境均无差异。
