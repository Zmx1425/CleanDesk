# CleanDesk 0.7.0-beta

## 新增

- 主题系统；
- 浅色与深色模式；
- 设置中的主题选择；
- 主题持久化；
- 动态主题切换。

## 优化

- 主窗口深色适配；
- 设置窗口深色适配；
- 规则列表与最近活动适配；
- 智能整理建议适配；
- 弹窗、日志与滚动条适配；
- 提升深色模式应用标题的文字对比度；
- 保持浅色模式原有视觉。

## 已知限制

- 当前仅支持浅色和深色；
- 暂不支持跟随 Windows；
- 暂不支持自定义主题色；
- 个别系统原生控件外观可能随 Windows 版本略有差异；
- Windows 通知显示受系统通知权限影响；
- 当前仅支持 Windows。
