# CleanDesk 0.7.0-beta 展示检查清单

展示前按顺序快速确认：

1. 解压 `CleanDesk_0.7.0-beta_Windows.zip` 到全新目录。
2. 启动 `CleanDesk/CleanDesk.exe`。
3. 添加测试文件夹 `CleanDesk_Demo`。
4. 新建 PDF 整理规则，目标文件夹可留空。
5. 点击“整理当前文件夹”。
6. 在“最近活动”中查看文件名、来源、目标位置和命中规则。
7. 点击“打开所在位置”。
8. 点击“撤销上一次整理”，确认文件回到原位置。
9. 在“设置 → 外观”切换深色模式并保存。
10. 将关闭窗口行为设为“最小化到系统托盘”，确认窗口可从托盘恢复。
11. 在设置中点击“发送测试通知”。
12. 从托盘菜单退出 CleanDesk。

展示注意事项：

- Windows 系统通知必须开启。
- 展示前关闭或删除真实的 CleanDesk 开机启动项。
- 只使用专门准备的测试文件夹。
- 不要使用重要真实文件进行演示。
