# CleanDesk 0.7.0-beta 测试记录

## 已自动验证

- 使用临时配置验证旧配置缺少 `theme` 时补齐为 `light`；
- 验证非法主题回退为 `light`，未知 settings 字段保留；
- 验证浅色、深色保存与重启保持；
- 验证设置取消不保存主题修改；
- 连续执行 `light → dark → light → dark`，QSS 未重复叠加；
- 验证主题切换不改变当前运行状态；
- 验证深色 QSS 覆盖主窗口、设置、菜单、列表、输入控件、滚动条、消息框和自定义弹窗；
- 验证智能整理建议滚动区域和建议项无白底漏网；
- 验证 `1600×900`、`1200×800` 与 `850×700` 的响应式模式和横向滚动策略；
- 使用两个临时目录验证文件夹添加、选择、移除、重复和嵌套校验；
- 验证普通规则、忽略规则、规则排序持久化、手动整理、Start/Stop、自动监听、智能建议和撤销；
- `python -m compileall .` 通过。

## 已目视检查

- 通过 Qt 离屏截图检查浅色与深色主窗口；
- 检查深色应用标题、副标题、卡片、文件夹列表、规则列表、最近活动、空状态和禁用按钮；
- 检查设置窗口上半部与下半部、固定按钮区和滚动条；
- 检查新建规则、忽略规则管理与编辑、智能整理建议；
- 检查删除、重名、撤销和普通信息消息框；
- 检查详细日志窗口；
- 浅色模式未发现深色残留或明显视觉退化。

## 既有人工 Windows 验证记录

- 0.6.x 阶段已确认系统托盘、关闭到托盘、托盘恢复与安全退出；
- 已确认 Windows 登录自启可用，并可静默进入托盘且不显示 CMD；
- 已确认真实 Windows 后台测试通知和手动整理汇总通知能够显示。

## 发布包复核

- PyInstaller 使用 windowed bootloader 构建成功，生成完整 `dist/CleanDesk` 目录；
- Windows ZIP 已解压到全新临时目录，`CleanDesk.exe` 不依赖源码 Python 即可启动；
- 普通启动后进程存活且主窗口标题为 `CleanDesk`；
- 应用自身 `--startup` 模式启动后进程存活，主窗口保持隐藏；
- 后台实例存在时再次普通启动，第二个进程快速退出并唤醒原窗口，实例数保持为 1；
- 使用无 BOM 的临时配置验证打包版可读取并保持 `dark` 主题；
- 构建配置使用 `--windowed` / `console=False`，未附带控制台窗口；
- Windows 自动化界面捕获因本机应用控制授权超时，未自动点击 About、主题下拉框、托盘菜单或测试通知按钮；
- PowerShell `CloseMainWindow()` 无法作为该 Qt windowed 进程的可靠退出自动化手段，测试进程已单独清理；托盘退出沿用 0.6.x 已有人工验证记录；
- Windows 原生控件在不同系统版本下的细微差异仍建议在目标机器复核；
- Windows 通知横幅是否展示取决于目标系统通知权限。

本记录仅描述实际执行或已有确认记录，不代表所有 Windows 环境均无差异。
