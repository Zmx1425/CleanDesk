# CleanDesk 0.6.0-beta

## 新增

- 设置中心；
- 启动后自动开始整理；
- 开始整理时扫描已有文件开关；
- 手动重名处理策略；
- 自动监听重名处理策略；
- 最近活动数量设置；
- 清空最近活动；
- 系统托盘；
- 关闭窗口行为设置；
- Windows 登录后自动启动；
- 开机静默进入托盘；
- 单实例运行。

## 优化

- 第二次启动会唤醒已有窗口；
- 防止创建重复 watcher 和重复托盘；
- 源码环境开机自启使用 `pythonw.exe`，不显示 CMD；
- 托盘退出会安全停止 watcher；
- 设置中心支持保存与取消；
- 清空活动后显示完成反馈。

## 已有能力

- 多监控文件夹；
- 自动整理规则与拖拽排序；
- 忽略规则；
- 智能整理建议；
- 最近活动与来源文件夹显示；
- 打开所在位置；
- 撤销上一次整理；
- 重名安全处理；
- 相对路径与绝对路径目标目录。

## 已知限制

- 当前仅支持 Windows；
- 所有监控文件夹共享规则和设置；
- 不支持单独启动或停止某一个监控文件夹；
- 不支持深色模式；
- 暂无 Windows 通知；
- 最近活动不跨重启保存；
- 撤销记录仅在当前程序运行期间保留。
