# CleanDesk Releases

此目录保存 CleanDesk 的正式版本留档，用于记录可复现的源码快照、发布包、更新记录与测试记录。

只归档实际生成并验证过的版本。早期未保存的版本不会在这里伪造历史快照。

每个版本目录通常包含：

- `CHANGELOG.md`：版本更新记录；
- `TEST_REPORT.md`：本次归档实际执行过的检查；
- `config.example.json`：不包含个人路径和真实运行数据的示例配置；
- `CleanDesk_<version>_Windows.zip`：Windows onedir 发布包；
- `CleanDesk_<version>_Source.zip`：源码快照。
