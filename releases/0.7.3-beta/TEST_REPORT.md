# CleanDesk 0.7.3-beta 测试报告

## 自动验证

- `python -m compileall .`：通过；
- `python -m unittest discover -s tests -v`：14 项测试通过；
- 覆盖手动整理与 watcher 来源区分；
- 覆盖前台抑制、后台聚合、通知关闭和退出清理；
- 覆盖真实 watchdog 信号经 service、UI 到通知聚合器的事件链；
- 覆盖启动扫描成功结果进入后台通知聚合器；
- 生产聚合时间保持 8 秒，测试使用可注入的短间隔。

## Windows 实机验证

- 手动整理成功不显示系统通知；
- 前台自动整理成功不显示系统通知；
- 隐藏到系统托盘后，自动整理成功会显示通知；
- 启动扫描成功结果会进入聚合通知；
- 8 秒聚合和文件数量统计正常。
