# CleanDesk 0.5.1-beta

## 新增 / 优化

- 首页 UI 重构，更适合多监控文件夹工作流；
- 控制中心合并运行状态与主要操作；
- 自动整理规则支持拖拽排序；
- 规则拖拽把手优化为更明确的三条横线；
- 规则拖拽顺序可持久保存；
- 撤销确认弹窗会显示涉及的来源文件夹；
- 无监控文件夹时点击操作按钮会提示用户先添加文件夹；
- 优化监控文件夹空状态；
- 关键词规则未填写目标目录时，可自动使用关键词创建相对目标文件夹；
- 确认对话框按钮统一中文化。

## 保留能力

- 多监控文件夹；
- 全局规则；
- 开始自动整理；
- 停止自动整理；
- 整理当前文件夹；
- 智能整理建议；
- 打开所在位置；
- 撤销上一次整理；
- 重名冲突处理；
- 相对路径与绝对路径目标文件夹。

## 已知限制

- 当前仅支持 Windows；
- 规则仍为全局共享，不支持每个文件夹独立规则；
- 不支持单个文件夹单独 Start/Stop；
- 撤销记录仅在本次程序运行期间有效。
