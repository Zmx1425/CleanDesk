# CleanDesk 0.5.0-beta

## 新增

- 多监控文件夹；
- 添加、选择、移除监控文件夹；
- 开始自动整理时扫描并监听所有监控文件夹；
- 整理当前文件夹只处理当前选中文件夹；
- 智能整理建议只分析当前选中文件夹；
- 最近活动显示来源文件夹。

## 保留能力

- 规则优先级；
- 智能整理建议；
- 打开所在位置；
- 撤销上一次整理；
- 重名冲突处理；
- 相对/绝对目标路径；
- Windows 打包运行。

## 已知限制

- 当前仅支持 Windows；
- 规则仍为全局共享，不支持每个文件夹独立规则；
- 不支持单个文件夹单独 Start/Stop；
- 撤销记录仅在本次程序运行期间有效。
